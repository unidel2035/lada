# Граф знаний культуролога

Интерактивная **модель знаний студента** философского факультета МГУ
(направление «Культурология»). По сути — граф прочитанных и непрочитанных
книг: узлы это книги и ключевые темы, рёбра — интеллектуальные связи между
текстами (влияние, полемика, развитие идей) и принадлежность темам.

Приложение полностью автономно: без внешних библиотек и CDN, силовая
раскладка графа написана вручную. Работает офлайн.

## Что показывает граф

- **Узлы-книги** окрашены по дисциплине (курсу), а их вид отражает статус чтения:
  - 🟢 **прочитано** — залитый круг;
  - 🟡 **читаю сейчас** — золотая обводка;
  - 🔵 **в планах** — полупрозрачный круг;
  - ⚪ **не прочитано** — пунктирный контур.
- **Узлы-темы** (Миф, Структурализм, Массовая культура, …) — прямоугольники-хабы,
  собирающие вокруг себя книги.
- **Рёбра** между книгами: «развивает идеи», «испытал влияние», «полемизирует»,
  «перекликается», «предшествует».
- Размер узла растёт с числом связей.

## Возможности

- Силовая раскладка с перетаскиванием узлов, зумом (колесо) и панорамой (фон).
- Подсветка соседей при наведении, панель деталей по клику: автор, год, оценка,
  краткая заметка, **развёрнутые «основные идеи»** (по 2 абзаца на книгу), темы,
  список интеллектуальных связей.
- Фильтры по статусу чтения и по дисциплинам, поиск по автору/названию.
- Индикатор прогресса чтения с разбивкой по статусам.

### Личный слой конспектов (в духе Obsidian)

- У любого узла (книга, тема, ключевое слово) можно вести **свой конспект**.
- Внутри конспекта пишите `[[ключевое слово]]` — оно становится отдельным узлом
  графа. Ключевые слова **связываются между собой**: откройте узел-слово и
  сошлитесь из него на другое `[[слово]]`.
- Панель показывает **обратные ссылки** («Упоминается в …») — как в Obsidian.
- Слой заметок включается/выключается тумблером; конспекты сохраняются в браузере
  (`localStorage`), есть **экспорт/импорт** заметок в JSON.

## Запуск

Требуется только Node.js (проверено на v22). Зависимостей нет.

```bash
# локальный сервер для разработки
npm start
# → http://localhost:5173/src/index.html

# проверить целостность данных
npm run validate

# собрать единый офлайн-файл dist/index.html (открывается двойным кликом)
npm run build
```

Готовый `dist/index.html` уже собран и лежит в репозитории — его можно просто
открыть в браузере без сервера.

## Структура проекта

```
data/
  knowledge-graph.json   # каноничная модель знаний: книги, темы, дисциплины, связи
src/
  index.html             # каркас приложения
  styles.css             # оформление (тёмная тема)
  graph.js               # силовая раскладка и отрисовка на SVG
  app.js                 # загрузка данных, фильтры, статистика, панель деталей
scripts/
  serve.mjs              # статический dev-сервер без зависимостей
  validate.mjs           # валидация ссылочной целостности данных
  build.mjs              # сборка единого офлайн-файла
dist/
  index.html             # собранная версия (данные + CSS + JS в одном файле)
```

## Как добавить свою книгу

Модель знаний живёт в `data/knowledge-graph.json`. Чтобы добавить книгу,
допишите объект в массив `books`:

```json
{
  "id": "eco-imya-rozy",
  "title": "Имя розы",
  "author": "У. Эко",
  "year": 1980,
  "status": "planned",
  "discipline": "semiotika",
  "themes": ["znak-simvol"],
  "note": "Семиотика и средневековая культура в форме романа."
}
```

Связи с другими книгами добавляются в массив `links`:

```json
{ "source": "eco-imya-rozy", "target": "eco-struktura", "type": "develops" }
```

Значения `status`, `discipline`, `themes` и `type` должны совпадать с id из
секций `meta.statuses`, `disciplines`, `themes` и `meta.linkTypes`. После правок
запустите `npm run validate` и `npm run build`.

## Данные

Корпус — **89 книг, 15 тем, 95 связей**. Основа — реальная **программа
государственного экзамена по культурологии философского факультета МГУ**
(документ ГИА филфака, `umk.philos.msu.ru`) плюс базовый канон дисциплины:
классики теории культуры (Каган, Флиер, Межуев, Миронов, Доброхотов, Кнабе),
цивилизационная теория (Данилевский, Шпенглер, Тойнби, Сорокин, Хантингтон),
семиотика и язык (Соссюр, Якобсон, Лотман, Барт, Эко, Пропп, Сепир, Выготский,
Вежбицкая), культурная антропология (Тайлор, Фрэзер, Малиновский, Леви-Стросс,
Гирц, Мосс, ван Геннеп, Тэрнер, Дуглас, Кребер, Эванс-Причард), философия мифа
(Лосев, Кассирер, Юнг, Элиаде), эстетика и визуальная культура (Аристотель,
Кант, Ницше, Бахтин, Панофский, Гомбрих, Вёльфлин), медиа и постмодерн (Беньямин,
Адорно, Маклюэн, Дебор, Бодрийяр, Фуко, Лиотар, Делёз/Гваттари, Саид, Бурдьё) и др.

У каждой книги есть развёрнутое поле `idea` с изложением основных идей. Статусы
чтения — иллюстративные; правьте под свою реальную траекторию.
